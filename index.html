Política de privacidad

clips-gta es una herramienta personal que usa una sola persona, el dueño del canal ClipZone. Sirve para subir vídeos a sus propias cuentas de YouTube, Instagram y TikTok. No tiene más usuarios.

  • Datos a los que accede: únicamente a las cuentas del propio dueño, con su permiso por OAuth. Los usa para publicar vídeos o enviarlos como borrador, y para comprobar que no haya duplicados.
  • Qué no hace: no recoge, no guarda, no vende y no comparte datos de otros usuarios. No muestra a terceros datos obtenidos de YouTube, Instagram o TikTok.
  • Dónde se guardan las claves: los tokens de acceso se guardan solo en el ordenador del dueño y no se envían a ningún servidor propio.
  • Cómo retirar el acceso o borrar los datos:
    • Google y YouTube: myaccount.google.com/permissions
    • Instagram: Configuración → Permisos de sitios web → Apps y sitios web.
    • TikTok: Configuración → Seguridad → Apps y servicios.
    Al retirar el acceso, el dueño borra también los tokens de su ordenador.
  • Servicios de terceros: esta herramienta usa los Servicios de API de YouTube. Al usarla se aceptan las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. También usa la API de Instagram (Meta) y la API de TikTok, y se rige por sus condiciones.
  • Contacto: clipsjuegosdavid@gmail.com

Privacy Policy (English)

clips-gta is a personal, single-user tool used only by the owner of the ClipZone channel. It uploads videos to the owner's own YouTube, Instagram and TikTok accounts.

  • Data accessed: only the owner's own accounts, through OAuth with the owner's consent. It is used to publish videos or send them as drafts, and to avoid duplicate uploads.
  • What it does not do: it does not collect, store, sell or share any third-party user data, and it does not display YouTube, Instagram or TikTok data to anyone else.
  • Where tokens are stored: access tokens are stored only on the owner's computer and are never sent to any other server.
  • Revoking access and deleting data: Google/YouTube at myaccount.google.com/permissions; Instagram under Settings → Website permissions; TikTok under Settings → Security → Apps and services. Local tokens are deleted when access is revoked.
  • Third-party services: this tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy. It also uses the Instagram API (Meta) and the TikTok API, subject to their terms.
  • Contact: clipsjuegosdavid@gmail.com
